Agent Capabilities

Classifier Agent

Uses LLM to determine whether uploaded document is a valid Electrical RFP. Prevents irrelevant documents from entering the pipeline.

Scope Agent

Extracts structured project details including materials, quantities, compliance requirements, and timeline.

Cost Agent

Combines vector-based semantic matching with deterministic Python pricing logic to generate accurate cost breakdown.

Proposal Agent

Generates professional bid proposal with executive summary, scope, technical approach, cost table, and conclusion.
